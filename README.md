# DFW Property-Services Lead Marketplace: backend

Follows the implementation spec v1.0 (2026-11-03). Public pages live in **Webflow**. Dashboard, admin, and API live in a small **Next.js** app (`/app`).
No social scraping and no logged-in bots. Social and community supply comes only through referral links and voluntary submissions (WF-03, not yet built).

```
supabase/migrations/20261103000000_init.sql   15 spec tables + 2 ops tables, enums, RLS, dedupe indexes, triggers, private bucket
supabase/test/shim.sql                         local-only auth/storage shim for linting outside Supabase
app/src/app/api/ai/classify                    Grok classification (structured outputs + Zod; uncertain → moderation_queue)
app/src/app/api/ai/chat                        Grok intake chat with ONLY the 7 approved tools (src/lib/grokTools.ts)
```

## Setup checklist (accounts + keys)
1. [ ] Domain + brand. Subdomain `app.` for the Next.js app. SPF/DKIM/DMARC for the sending domain.
2. [ ] **GitHub** repo (push this one).
3. [ ] **Vercel** project rooted at `/app` (Node 22+). Add all server env vars from `.env.example`.
4. [ ] **Supabase** (Pro recommended for production): `supabase link` then `supabase db push`. Create the first admin user, then `update profiles set role='admin' where user_id='<uuid>'`.
   Insert source rows (SAM.gov `official_api`, `reuse_allowed`/`active` after terms review). Add a **Database Webhook** on `opportunities` UPDATE → n8n WF-04 URL with header `x-shared-secret`.
   Auth: enable email magic link, and set the Site URL to `NEXT_PUBLIC_APP_URL` and the redirect to `/auth/callback`.
5. [ ] **xAI** console: API key + spend cap. Confirm `XAI_MODEL` on docs.x.ai.
6. [ ] **n8n Cloud**: import the 5 JSONs. Create a Header Auth credential "Supabase service role" (`apikey` + `Authorization: Bearer <service key>`) and a Header Auth credential for webhooks (`x-shared-secret`). Set env/variables `APP_URL, SUPABASE_URL, N8N_WEBHOOK_SHARED_SECRET, RESEND_API_KEY, ALERT_FROM_EMAIL, OPS_ALERT_EMAIL, SAM_GOV_API_KEY, SAM_SOURCE_ID`. Set WF-09 as the error workflow on the others. Add a 15-min schedule that POSTs `/api/webflow/sync`.
7. [ ] **Resend**: verify the domain and create an API key.
8. [ ] **Stripe** (test mode): 2 products/prices ($99 Local Pro, $199 Multi-Trade, labeled test pricing). Webhook → `/api/stripe/webhook` for `checkout.session.completed, customer.subscription.created/updated/deleted, invoice.paid, invoice.payment_failed`. Checkout sessions must set `subscription_data.metadata.organization_id`.
9. [ ] **Cloudflare Turnstile**: site key (Webflow embed) + secret.
10. [ ] **Webflow**: API token (CMS:write) and the Opportunities collection (see docs).
11. [ ] **SAM.gov**: account and public API key (Account Details page).
12. [ ] Google Search Console. Sentry/PostHog optional (mask PII).

## Launch quality checks (spec §9) and where they're covered
- Withdrawn/unknown consent never exposes contacts → RLS `has_lead_access` + `consents_withdrawn` trigger (sql-lint ✔)
- Same source record twice → one opportunity → `opportunities_source_dedupe` / `raw_ingestions_dedupe` (sql-lint ✔)
- Contractor can't see another org's billing/leads → RLS (sql-lint ✔)
- Prompt injection / malformed JSON / timeouts → `wrapUntrusted`, Zod re-validation, failures → moderation_queue (unit tests ✔)
- Webhook replay → `stripe_events` PK (manual test with `stripe trigger` still needed)
- Old/cancelled bids → WF-06 expire + `suppress_closed_notifications`
- Test data → `is_test_data` can never be `public` (DB constraint ✔)
